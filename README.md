"HALCYON BAY": an open-world crime game — explore a coastal city on foot and by car, steal cars, outrun the police, climb the wanted ladder, and run 12 story missions across 3 days for Mara Solis and Old Sal. Police helicopters, per-district heat, a reputation ladder from NOBODY to KING OF HALCYON, and RICO'S GARAGE with car collection and upgrades. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step — the game is static files under `game/`.
